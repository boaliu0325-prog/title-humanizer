# Title Humanizer

让标题"说人话"——先搞清楚读者是谁，再站在读者角度重新表达。

## 为什么做这个

很多人学AI的方式是反过来的——不是先想清楚自己要表达什么，再用AI帮忙，而是把所有事都交给AI，自己只管复制粘贴。

结果就是：互联网上到处都是AI味儿的内容，看起来专业，但读完什么也没记住。

很多人做自媒体觉得自己"没有方向"，其实不是没有方向，是没有找到方法去**训练自己想清楚**。这个工具会问你一些问题——读者是谁、他们关心什么、他们管那个东西叫什么。这些问题不是为了麻烦你，而是让你时刻记住：你在向谁表达，他们为什么要听你说。

目前是标题，之后会扩展到文案、脚本。AI可以帮你提效，但"想清楚给谁看"这件事，得你自己来。

## 解决什么问题

很多标题让人看不懂，不是因为词太难，而是因为没有站在读者的角度去写。

**原标题：** 这个prompt太好用了直接出片

→ "prompt"是什么？"出片"是什么？普通读者完全看不懂。

**优化后：** Midjourney输入这句话，直接生成好看的图

→ 读者一眼知道在说什么、跟自己有没有关系。

## 怎么用

在 Claude Code 中输入以下任一触发词即可：

- `标题优化`、`标题说人话`、`标题改写`
- `帮我看看这个标题`
- `这个标题怎么样`
- 做自媒体内容需要起标题时

Skill 会先问你读者是谁，再基于读者的认知写标题。

## 工作流程

1. **问清楚** — 先确认读者是谁、关键信息是什么（一次一问）
2. **读懂** — 分析作者想说什么、读者关心什么
3. **术语检查** — 基于读者判断哪些词他们能懂
4. **自查+交流** — 跟用户确认分析结果
5. **输出标题** — 从读者角度写标题，附自查表格
6. **优化（可选）** — 加情绪钩子、数字、身份代入等
